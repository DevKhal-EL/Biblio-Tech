# Biblio-Tech

Projeto acadêmico de desenvolvimento de um sistema de gerenciamento de biblioteca.

O repositório reúne a versão inicial do Biblio-Tech e sua evolução a partir de uma adaptação com banco de dados relacional, desenvolvida no contexto das atividades acadêmicas.

## Estado atual

O projeto está em processo de integração, organização e documentação. A estrutura e o código existentes serão revisados para dar continuidade ao desenvolvimento.

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- MySQL

## Documentação

A documentação do projeto está sendo reorganizada e será atualizada com informações sobre seu planejamento, histórico de desenvolvimento, arquitetura e próximos objetivos.
